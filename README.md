# japan-food-tourism-economics
An AI-assisted Python research project investigating how social media has contributed to Japan's popularity as a food tourism destination, exploring the potential relationship between tourism demand, GDP, and inflation through economic research, data analysis, graphs, and an interactive visualisation.

Objectives

- Explore social media's influence on food tourism.
- Investigate potential links between tourism demand and economic indicators.
- Present research questions and data through graphs and an interactive interface.

Tools Used

- Python
- AI-assisted development
- Data visualisation
